## 一、自动化接口测试：86/86 全部通过

测试脚本按六大阶段执行（注册 3 个患者账号 + 管理员建医生账号，均为真实写库）：

### 阶段 1 · 认证与账号（14 项）
- 三类角色登录签发 JWT；登录响应不回传密码（WRITE_ONLY）
- 错误密码拒绝（400）；重复账号注册拒绝；无 Token 访问返回 401；患者访问管理员接口返回 403
- 找回密码：手机号匹配可重置 / 不匹配拒绝；修改资料、修改密码正常

### 阶段 2 · 科室 / 医生 / 排班（10 项）
- 科室列表为种子数据 8 条，新增后变 9 条（真实库计数）
- 患者端医生列表仅显示资质审核通过的医生；医生列表正确关联科室名
- 批量排班 3 天 × 2 时段 = 6 条；重复排班自动跳过（唯一键防冲突）

### 阶段 3 · 预约全流程（13 项）
- 号源防超卖：2 个号源 → 前两人成功、第三人被拒（数据库行锁原子扣减）
- 取消预约后号源释放，他人可再约
- 无号源预约进入「待派单」池；线下登记统一入池；患者派单被 403 拦截；管理员派单成功；重复派单被拒
- 数据隔离：患者只见自己的预约，医生只见自己的接诊单

### 阶段 4 · 病历 → 处方 → 缴费 → 发药（16 项）
- 非接诊医生写病历被 403；接诊医生填写病历后预约自动完结；同一预约重复病历被拒
- 处方金额自动按明细计算（15.80×2 + 18.50 = 49.10 验证通过）
- 未缴费发药被拒；重复缴费被拒；发药后库存 -2 且生成 2 条出库流水（含前后库存）
- 已发药处方不可作废；未缴费处方可作废；病历不存在时开方被拒

### 阶段 5 · 评价 / 资质审核 / 停诊联动（12 项）
- 患者评价完成就诊；重复评价、冒名评价均被拒；医生可回复
- 医生提交资质 → 管理员审核通过 → 状态联动；重复审核被拒
- 停诊自动取消该排班下未完成预约并注明「医生停诊」原因；恢复出诊正常

### 阶段 6 · 药品 / 系统 / 统计（18 项）
- 入库 +50 库存验证；库存调负被拒；新增药品/供应商
- 冻结账号后禁止登录（403）；解冻后恢复
- 5 个统计接口（总览/趋势/科室分布/接诊量/药品消耗）均返回真实聚合数据
